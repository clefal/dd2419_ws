# Controller – Internal Documentation

## Purpose

The Controller tracks the global path and generates motor duty cycles for a differential-drive robot.

It implements **Pure Pursuit** with optional final yaw alignment.

All control operates in the **map frame**, using TF for pose estimation.

---

## Inputs

### Subscribed Topics
- `/nav/global_path` (nav_msgs/Path)  
  Path generated by the Global Planner.

### TF
- `map → base_link`  
  Used to compute robot pose.

---

## Control Strategy

1. Extract robot pose (x, y, yaw).
2. Find closest path point.
3. Select lookahead point.
4. Compute curvature using Pure Pursuit:
   - κ = 2y / L²
5. Convert (v, ω) to left/right duty cycles.
6. Enforce motor deadzone constraints.
7. Publish commands.

When near final position:
- Stop translation.
- Align to final yaw (if enabled).
- Publish `REACHED` when complete.

---

## Outputs

### Published Topics
- `/phidgets/motor/duty_cycles` (DutyCycles)  
  Left and right motor commands.

- `/nav/status` (String)  
  `RUNNING`, `REACHED`, or `FAILED`.

- `/nav/is_turning` (Bool)  (for lidar mapping)
  Indicates turn-in-place behavior.

---

## Key Parameters

- `lookahead_distance` – Pure Pursuit lookahead.
- `nominal_linear_speed` – Forward speed.
- `max_angular_speed` – Angular velocity limit.
- `goal_tolerance` – Position tolerance.
- `align_final_yaw` – Enable final orientation alignment.
- `steering_gain` – Curvature scaling.

---

## Notes

- Path frame must be `map`.
- Stops automatically if no path is available.
- Designed for indoor, low-speed navigation.
